## 3. 选型风险与验证点

- Python/Node/OpenSpec 版本变化：阶段工具链检查确认实际版本并在升级时复核脚本兼容性。
- 本地 JSON 不适于跨仓库并发状态服务：如引入远程调度/多租户，须做新 ADR 和安全评估。
- 外部 Figma MCP 依赖实际宿主权限：不可读节点时 UI 流程阻塞，不降级为截图替代。
- 12,000 字符预算需真实 Change 试点复核；这不改变用户当前确认的目标值。
