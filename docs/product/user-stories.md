## 验收标准

### AC-001

- Given：种植员/养殖员已登录且所选地块（温室/大田/畜舍/池塘）的设备在线并有上报数据
- When：打开环境监测页面并选择该地块
- Then：显示各环境指标实时值与最近上报时间，并可切换历史曲线
- 错误/边界：设备离线时显示离线提示与最后上报时间，不显示空白页

### AC-002

- Given：作业人员已登录且有该设备控制权限，设备在线
- When：下发"开泵 30 分钟"指令并确认
- Then：系统记录操作人、时间、指令（BR-003），并显示执行回执
- 错误/边界：设备离线 → 拒绝下发并提示；重复快速点击 → 不产生重复指令（幂等）

### AC-003

- Given：农场管理员已登录且有预警配置权限
- When：修改某指标阈值并保存
- Then：新阈值生效且修改历史可查（BR-004）
- 错误/边界：阈值非法（如最低值大于最高值）→ 拒绝保存并提示

### AC-004

- Given：作业人员已登录且有该地块录入权限
- When：填写一条作业记录（类型、内容、时间）并保存
- Then：记录保存成功并关联地块；涉及农资消耗时扣减库存（BR-007）
- 错误/边界：必填项缺失 → 拒绝保存并提示；补录历史作业时记录标记为补录

### AC-005

- Given：采购员已登录且有农资管理权限
- When：登记一批农资入库（品名、数量、批次）
- Then：库存数量增加且入库记录可查
- 错误/边界：数量为 0 或负数 → 拒绝；重复提交同一次入库 → 不产生重复库存（幂等）

### AC-006

- Given：农场管理员已登录，批次已关联作业记录且检测报告已上传（BR-002）
- When：为该批次生成溯源码
- Then：生成全局唯一溯源码（BR-001，批次一码）并支持打印/导出
- 错误/边界：缺检测报告 → 按 BR-002 拦截并提示；同批次重复生成 → 拒绝

### AC-007

- Given：溯源码有效且已发布
- When：消费者用手机扫码
- Then：无需登录即可打开溯源页，查看产地环境、作业记录与检测信息
- 错误/边界：码无效或未发布 → 显示无效提示；部分数据缺失 → 显示可见部分并标注缺失

### AC-008

- Given：系统管理员已登录
- When：创建一个"种植员/养殖员"角色用户并分配地块权限
- Then：该用户只能看到被分配地块的数据与对应功能
- 错误/边界：该用户访问其他地块或管理员功能 → 拒绝（403 类错误，具体形态设计阶段定）

### AC-009

- Given：政府监管人员已登录且被分配辖区
- When：打开监管端汇总看板并选择该辖区
- Then：显示辖区内农场的汇总数据（环境、预警、批次、溯源覆盖），并可下钻单个农场详情
- 错误/边界：无辖区数据 → 显示空态提示；监管人员尝试下发控制指令或修改数据 → 拒绝（只读）

### AC-010

- Given：农场管理员已登录且地块、品种（含畜禽/水产品类）档案就绪
- When：创建一份生产计划（品种、地块/塘口、茬口/养殖周期、目标产量）并引用农事模板后发布
- Then：计划保存并进入生效状态，可作为农事任务的生成来源
- 错误/边界：必填项（品种、地块、周期）缺失 → 拒绝发布并提示；计划调整时已执行的任务记录保留不删

### AC-011

- Given：一份已发布的生产计划引用了农事模板（各生长期标准作业）
- When：进入对应生长期或到达模板设定的时点
- Then：系统自动生成农事任务（含责任人、时限、作业内容）并派发；任务状态可查
- 错误/边界：模板缺失对应生长期作业 → 不生成并记录缺口；重复触发生成 → 不产生重复任务（幂等）

### AC-012

- Given：作业人员已登录且有一条派发给自己的待执行任务
- When：接单执行并在移动端提交完成记录（含作业内容与农资消耗）
- Then：任务状态更新为待审核，管理员审核通过后任务闭环（Q-010 已决）；执行记录关联回任务（BR-008），农资消耗扣减库存（BR-007）
- 错误/边界：必填项缺失 → 拒绝提交；非责任人尝试操作该任务 → 拒绝；逾期提交 → 记录标记逾期；审核驳回 → 任务退回并注明原因
