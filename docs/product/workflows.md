# 业务流程

> 状态：DRAFT v0.1（2026-10-30）；来源：网络调研（见 requirements-analysis.md 来源清单）+ 建议方案，全部待用户确认。
> 已决策（2026-10-30）：业务范围为种植+畜牧+水产全覆盖（Q-006）；系统含政府监管端（Q-001，监管汇总能力见 UC-008）；不含销售/商城/认养等经营模块（Q-004）。
> 环境监测（FLOW-001）同时覆盖种植（温室/大田）与养殖（畜舍/池塘）场景；未覆盖流程（销售、认养）不再纳入。

## FLOW-001：环境监测与预警

- 状态：待确认
- 业务目标：实时掌握园区/温室环境状况，异常自动预警，支撑农事决策
- 参与者/系统：传感器设备、采集网关、系统（采集/预警）、种植员、农场管理员
- 触发条件：传感器按配置周期上报数据；或管理员手动刷新
- 前置条件：设备已注册并在线；预警阈值已配置（BR-004）
- 主流程：
  1. 传感器上报环境数据（温湿度、土壤、CO2、光照等，RA-002）
  2. 系统校验数据并入库，更新地块/温室实时环境状态
  3. 系统按阈值规则比对，超限则生成预警记录并通知（种植员/管理员）
  4. 用户在监测页面查看实时数据、历史曲线与预警列表
- 替代流程：3a. 数据在阈值内 → 仅入库与展示，不预警
- 异常流程：设备离线/超时未上报 → 系统标记设备离线并生成设备异常通知；数据非法（超出物理量程）→ 拒绝入库并记录
- 后置条件：环境数据可查、预警可追溯、设备状态准确
- 关联 UC/US/BR/AC：UC-001、UC-002、UC-007；US-001~US-003；BR-003、BR-004；AC-001~AC-003
- 来源与审批：网络调研（RA-001/RA-002）；待用户确认

## FLOW-002：农事作业记录

- 状态：待确认
- 业务目标：农事作业（播种、施肥、灌溉、用药、采收）全程留痕，支撑溯源与统计
- 参与者/系统：种植员/养殖员、农场管理员、系统（农事管理）、农资库存（BR-007）
- 触发条件：种植员按农事计划或实际作业录入
- 前置条件：地块/温室已建档；种植员已登录且有该地块权限
- 主流程：
  1. 种植员/养殖员选择地块（温室/大田/畜舍/池塘）与作业类型，填写作业内容（如肥料种类/剂量、用药、投喂、防疫、捕捞、作业时间）
  2. 涉及农资消耗的作业扣减农资库存（BR-007）
  3. 系统保存农事记录，关联地块与（采收后）批次
  4. 管理员可按地块/时间/类型查询与导出农事记录
- 替代流程：1a. 补录历史作业（补录标记，区别于实时录入）
- 异常流程：必填项缺失/格式非法 → 拒绝保存并提示；农资库存不足 → 提示并要求先入库（待确认）
- 后置条件：农事记录完整、可追溯、统计准确
- 关联 UC/US/BR/AC：UC-003、UC-006；US-004~US-005；BR-005、BR-007；AC-004~AC-005
- 来源与审批：网络调研（RA-001/RA-005）；待用户确认

## FLOW-003：农产品批次溯源

- 状态：待确认
- 业务目标：采收批次生成唯一溯源码，消费者扫码可查生产全过程，提升产品可信度
- 参与者/系统：农场管理员、系统（溯源管理）、消费者（扫码页）
- 触发条件：批次采收完成，管理员发起生成溯源码
- 前置条件：批次已关联地块与农事记录；该批次检测报告已上传（RA-005/BR-002，是否强制见 Q-008 建议）
- 主流程：
  1. 管理员选择采收批次，核对农事记录与检测报告
  2. 系统生成唯一溯源码（BR-001）并支持打印/导出
  3. 消费者扫码打开溯源页，查看产地环境、农事记录、认证与检测信息（RA-003）
  4. 消费者可提交反馈（是否在范围见 Q-004）
- 替代流程：2a. 缺检测报告 → 按业务规则拦截并提示（BR-002）
- 异常流程：扫码页面数据缺失 → 显示可见部分并标注缺失；溯源码重复生成 → 拒绝（BR-001）
- 后置条件：批次与溯源码绑定，扫码可查、来源可追
- 关联 UC/US/BR/AC：UC-004、UC-005；US-006~US-007；BR-001、BR-002；AC-006~AC-007
- 来源与审批：网络调研（RA-003/RA-005）；待用户确认
