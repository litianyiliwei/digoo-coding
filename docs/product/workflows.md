## FLOW-004：生产计划与农事任务派工

- 状态：已确认（2026-11-05）
- 业务目标：以计划驱动生产，任务到人、时限明确，避免农事遗漏延误（借鉴 MES 计划排程/工单管理，RA-009/RA-010）
- 参与者/系统：农场管理员（制定计划/审核）、系统（按模板生成任务）、种植员/养殖员（执行）
- 触发条件：新茬口/新生产周期开始；或按农事模板周期自动生成
- 前置条件：地块（温室/大田/畜舍/池塘）、品种（含畜禽/水产品类）档案就绪；农事模板已维护（Q-011 已决：管理员维护，系统预置示例模板）
- 模板演进说明：远期农事模板演进为"区域+物种生命周期模型"（生老病死各阶段、每阶段任务、每平方米/每头每只/每塘口物料定额，RA-012，不阻塞一期）；一期模板结构须预留品种、区域、生长阶段、单位定额四个维度
- 主流程：
  1. 管理员制定生产计划：品种、地块/塘口、茬口/养殖周期、目标产量、计划作业安排
  2. 系统按农事模板与生长期自动生成农事任务（或管理员手动创建）
  3. 任务派发给作业人员（责任人、时限），状态为待执行
  4. 作业人员执行任务并在移动端提交完成记录（进入 FLOW-002）
  5. 管理员审核任务完成情况，审核通过后任务闭环（Q-010 已决：需审核，可配置开关）
- 替代流程：2a. 临时任务（计划外，如突发病虫害处置）由管理员/作业人员创建，标注临时来源（BR-008）
- 异常流程：任务逾期未完成 → 系统提醒/升级通知；计划调整 → 未执行任务重新排期，已执行记录保留
- 后置条件：计划-任务-记录-批次全链路可追溯（BR-009）
- 关联 UC/US/BR/AC：UC-009、UC-010；US-010~US-012；BR-008、BR-009；AC-010~AC-012
- 来源与审批：网络调研（RA-009/RA-010）+ 用户核心业务定位；待用户确认

## FLOW-001：环境监测与预警

- 状态：已确认（2026-11-05）
- 业务目标：实时掌握园区/温室/养殖场环境状况，异常自动预警，支撑农事决策
- 参与者/系统：传感器设备、采集网关、系统（采集/预警）、种植员/养殖员、农场管理员
- 触发条件：传感器按配置周期上报数据；或管理员手动刷新
- 前置条件：设备已注册并在线；预警阈值已配置（BR-004）
- 主流程：
  1. 传感器上报环境数据（温湿度、土壤、CO2、光照等，RA-002）
  2. 系统校验数据并入库，更新地块/温室/养殖场实时环境状态
  3. 系统按阈值规则比对，超限则生成预警记录并通知（种植员/养殖员/管理员）
  4. 用户在监测页面查看实时数据、历史曲线与预警列表
- 替代流程：3a. 数据在阈值内 → 仅入库与展示，不预警
- 异常流程：设备离线/超时未上报 → 系统标记设备离线并生成设备异常通知；数据非法（超出物理量程）→ 拒绝入库并记录
- 后置条件：环境数据可查、预警可追溯、设备状态准确
- 关联 UC/US/BR/AC：UC-001、UC-002、UC-007；US-001~US-003；BR-003、BR-004；AC-001~AC-003
- 来源与审批：网络调研（RA-001/RA-002）；待用户确认

## FLOW-002：农事作业执行与记录

- 状态：已确认（2026-11-05）
- 业务目标：农事作业（播种、施肥、灌溉、用药、采收、投喂、防疫、捕捞）全程留痕，支撑溯源与统计；v0.4 起作业记录关联农事任务（工单执行，FLOW-004）
- 参与者/系统：种植员/养殖员、农场管理员、系统（农事管理）、农资库存（BR-007）
- 触发条件：种植员/养殖员按农事计划或实际作业录入
- 前置条件：地块（温室/大田/畜舍/池塘）已建档；作业人员已登录且有该地块权限
- 主流程：
  1. 种植员/养殖员选择地块与作业类型（关联农事任务则自动带出，见 FLOW-004），填写作业内容（如肥料种类/剂量、用药、投喂、防疫、捕捞、作业时间）
  2. 涉及农资消耗的作业扣减农资库存（BR-007）
  3. 系统保存作业记录，关联地块与（采收/出栏后）批次
  4. 管理员可按地块/时间/类型查询与导出作业记录
- 替代流程：1a. 补录历史作业（补录标记，区别于实时录入）
- 异常流程：必填项缺失/格式非法 → 拒绝保存并提示；农资库存不足 → 提示并要求先入库（待确认）
- 后置条件：作业记录完整、可追溯、统计准确
- 关联 UC/US/BR/AC：UC-003、UC-006；US-004~US-005；BR-005、BR-007；AC-004~AC-005
- 来源与审批：网络调研（RA-001/RA-005）；待用户确认

## FLOW-003：农产品批次溯源

- 状态：已确认（2026-11-05）
- 业务目标：采收/出栏批次生成唯一溯源码（批次一码，Q-008 已决），消费者扫码可查生产全过程，提升产品可信度
- 参与者/系统：农场管理员、系统（溯源管理）、消费者（扫码页）
- 触发条件：批次采收/出栏完成，管理员发起生成溯源码
- 前置条件：批次已由作业记录形成（种植采收/养殖出栏），并关联计划、地块、投入品、作业与质检记录（BR-009）；该批次检测报告已上传（RA-005/BR-002，已决策为强制）
- 主流程：
  1. 采收/出栏后进行简单入库登记（批次、数量、日期），形成生产批次（Q-012 已决）
  2. 管理员选择采收/出栏批次，核对作业记录与检测报告
  3. 系统生成唯一溯源码（BR-001，批次一码）并支持打印/导出
  4. 消费者扫码打开溯源页，查看产地环境、作业记录、认证与检测信息（RA-003）
  5. 消费者扫码查询行为被统计（支撑成功指标）
- 替代流程：3a. 缺检测报告 → 按业务规则拦截并提示（BR-002）
- 异常流程：扫码页面数据缺失 → 显示可见部分并标注缺失；溯源码重复生成 → 拒绝（BR-001）
- 后置条件：批次与溯源码绑定，扫码可查、来源可追
- 关联 UC/US/BR/AC：UC-004、UC-005；US-006~US-007；BR-001、BR-002；AC-006~AC-007
- 来源与审批：网络调研（RA-003/RA-005）；待用户确认
