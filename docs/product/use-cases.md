# 功能用例

> 状态：DRAFT v0.1（2026-10-30）；来源：网络调研 + 建议方案，全部待用户确认。

## UC-001：查看环境实时数据与历史曲线

- 目标/价值：种植员/管理员随时掌握温室与地块环境状况（RA-002）
- 参与者：种植员、农场管理员
- 触发器：打开环境监测页面
- 前置条件：已登录；设备在线且已上报数据
- 主成功场景：选择地块/温室 → 查看实时环境指标 → 切换查看历史曲线与统计
- 扩展/异常：无数据（设备离线）→ 显示设备离线提示与最后上报时间
- 后置条件：无数据变更（只读用例）
- 关联 FLOW/US/BR/AC：FLOW-001；US-001；AC-001
- 状态/来源/审批人：待确认 / 网络调研 / PENDING

## UC-002：远程控制灌溉等设备

- 目标/价值：远程执行灌溉/通风等作业，减少人工到场（RA-001）
- 参与者：种植员（或管理员）
- 触发器：在设备控制页下发控制指令
- 前置条件：已登录且有该设备权限；设备在线
- 主成功场景：选择设备 → 选择动作（开/关/时长）→ 确认下发 → 系统记录操作（BR-003）→ 显示执行结果
- 扩展/异常：设备离线 → 拒绝下发并提示；指令超时无回执 → 标记执行未知并允许重试（待确认）
- 后置条件：控制指令与结果留痕可审计
- 关联 FLOW/US/BR/AC：FLOW-001；US-002；BR-003；AC-002
- 状态/来源/审批人：待确认 / 网络调研 / PENDING

## UC-003：记录农事作业

- 目标/价值：农事作业全程留痕，支撑统计与溯源（RA-001/RA-005）
- 参与者：种植员
- 触发器：完成或计划一项农事作业
- 前置条件：地块已建档；有该地块录入权限
- 主成功场景：选地块 → 选作业类型（播种/施肥/灌溉/用药/采收）→ 填写内容与时间 → 保存
- 扩展/异常：补录 → 标记补录来源；农资消耗 → 扣减库存（BR-007，不足时流程待确认）
- 后置条件：农事记录保存并关联地块/批次
- 关联 FLOW/US/BR/AC：FLOW-002；US-004；BR-007；AC-004
- 状态/来源/审批人：待确认 / 网络调研 / PENDING

## UC-004：生成批次溯源码

- 目标/价值：为采收批次生成唯一溯源码，实现一物一码（RA-003）
- 参与者：农场管理员
- 触发器：批次采收完成后发起
- 前置条件：批次已关联农事记录；检测报告已上传（BR-002，是否强制见 Q-008）
- 主成功场景：选批次 → 核对记录完整性 → 生成唯一溯源码 → 打印/导出
- 扩展/异常：缺检测报告 → 按 BR-002 拦截并提示；重复生成 → 拒绝（BR-001）
- 后置条件：溯源码与批次绑定
- 关联 FLOW/US/BR/AC：FLOW-003；US-006；BR-001、BR-002；AC-006
- 状态/来源/审批人：待确认 / 网络调研 / PENDING

## UC-005：消费者扫码查询溯源信息

- 目标/价值：提升产品透明度与可信度（RA-003）
- 参与者：消费者（无需登录，待确认）
- 触发器：扫描产品包装溯源二维码
- 前置条件：溯源码有效且已发布
- 主成功场景：扫码 → 打开溯源页 → 查看产地、农事记录、认证与检测信息
- 扩展/异常：码无效/未发布 → 显示无效提示；部分数据缺失 → 显示可见部分并标注
- 后置条件：查询行为可统计（访问计数，支撑成功指标）
- 关联 FLOW/US/BR/AC：FLOW-003；US-007；AC-007
- 状态/来源/审批人：待确认 / 网络调研 / PENDING

## UC-006：农资出入库管理

- 目标/价值：农资采购、库存与消耗全生命周期管理（RA-004）
- 参与者：采购员（或管理员）
- 触发器：采购入库或农事消耗出库
- 前置条件：已登录且有农资管理权限
- 主成功场景：登记采购入库（品名/数量/批次）→ 库存增加；农事消耗 → 库存扣减（BR-007）
- 扩展/异常：库存不足扣减 → 提示并阻止（待确认）；重复提交 → 幂等处理
- 后置条件：库存账实一致、消耗可追溯
- 关联 FLOW/US/BR/AC：FLOW-002；US-005；BR-007；AC-005
- 状态/来源/审批人：待确认 / 网络调研 / PENDING

## UC-007：配置与处理预警

- 目标/价值：异常情况及时发现与处理（RA-001/RA-002）
- 参与者：农场管理员（配置）、种植员（处理）
- 触发器：管理员配置阈值；系统产生预警
- 前置条件：已登录且有相应权限
- 主成功场景：管理员设定指标阈值与通知对象（BR-004）→ 系统产生预警 → 种植员查看并标记处理结果
- 扩展/异常：阈值修改留存历史；预警通知失败 → 重试并记录（待确认）
- 后置条件：预警可追溯、处理结果留痕
- 关联 FLOW/US/BR/AC：FLOW-001；US-003；BR-004；AC-003
- 状态/来源/审批人：待确认 / 网络调研 / PENDING
