## UC-001：查看环境实时数据与历史曲线

- 目标/价值：种植员/养殖员/管理员随时掌握温室、大田、畜舍、池塘环境状况（RA-002）
- 参与者：种植员/养殖员、农场管理员
- 触发器：打开环境监测页面
- 前置条件：已登录；设备在线且已上报数据
- 主成功场景：选择地块/温室/养殖场 → 查看实时环境指标 → 切换查看历史曲线与统计
- 扩展/异常：无数据（设备离线）→ 显示设备离线提示与最后上报时间
- 后置条件：无数据变更（只读用例）
- 关联 FLOW/US/BR/AC：FLOW-001；US-001；AC-001
- 状态/来源/审批人：已确认 / 网络调研 / 用户（2026-11-05）

## UC-002：远程控制灌溉等设备

- 目标/价值：远程执行灌溉/通风等作业，减少人工到场（RA-001）
- 参与者：种植员/养殖员（或管理员）
- 触发器：在设备控制页下发控制指令
- 前置条件：已登录且有该设备权限；设备在线
- 主成功场景：选择设备 → 选择动作（开/关/时长）→ 确认下发 → 系统记录操作（BR-003）→ 显示执行结果
- 扩展/异常：设备离线 → 拒绝下发并提示；指令超时无回执 → 标记执行未知并允许重试（待确认）
- 后置条件：控制指令与结果留痕可审计
- 关联 FLOW/US/BR/AC：FLOW-001；US-002；BR-003；AC-002
- 状态/来源/审批人：已确认 / 网络调研 / 用户（2026-11-05）

## UC-003：记录农事作业

- 目标/价值：农事作业全程留痕，支撑统计与溯源（RA-001/RA-005）
- 参与者：种植员/养殖员
- 触发器：完成或计划一项作业
- 前置条件：地块已建档；有该地块录入权限
- 主成功场景：选地块（温室/大田/畜舍/池塘）→ 选作业类型（播种/施肥/灌溉/用药/采收/投喂/防疫/捕捞）→ 填写内容与时间 → 保存
- 扩展/异常：补录 → 标记补录来源；农资消耗 → 扣减库存（BR-007，不足时流程待确认）
- 后置条件：作业记录保存并关联地块/批次
- 关联 FLOW/US/BR/AC：FLOW-002；US-004；BR-007；AC-004
- 状态/来源/审批人：已确认 / 网络调研 / 用户（2026-11-05）

## UC-004：生成批次溯源码

- 目标/价值：为采收/出栏批次生成唯一溯源码，实现批次一码（RA-003，Q-008 已决）
- 参与者：农场管理员
- 触发器：批次采收/出栏完成后发起
- 前置条件：批次已关联作业记录；检测报告已上传（BR-002，已决策为强制）
- 主成功场景：选批次 → 核对记录完整性 → 生成唯一溯源码 → 打印/导出
- 扩展/异常：缺检测报告 → 按 BR-002 拦截并提示；重复生成 → 拒绝（BR-001）
- 后置条件：溯源码与批次绑定
- 关联 FLOW/US/BR/AC：FLOW-003；US-006；BR-001、BR-002；AC-006
- 状态/来源/审批人：已确认 / 网络调研 / 用户（2026-11-05）

## UC-005：消费者扫码查询溯源信息

- 目标/价值：提升产品透明度与可信度（RA-003）
- 参与者：消费者（无需登录，待确认）
- 触发器：扫描产品包装溯源二维码
- 前置条件：溯源码有效且已发布
- 主成功场景：扫码 → 打开溯源页 → 查看产地、作业记录、认证与检测信息
- 扩展/异常：码无效/未发布 → 显示无效提示；部分数据缺失 → 显示可见部分并标注
- 后置条件：查询行为可统计（访问计数，支撑成功指标）
- 关联 FLOW/US/BR/AC：FLOW-003；US-007；AC-007
- 状态/来源/审批人：已确认 / 网络调研 / 用户（2026-11-05）

## UC-006：农资出入库管理

- 目标/价值：农资采购、库存与消耗全生命周期管理（RA-004）

- 触发器：采购入库或农事消耗出库

- 后置条件：库存账实一致、消耗可追溯
- 关联 FLOW/US/BR/AC：FLOW-002；US-005；BR-007；AC-005
- 状态/来源/审批人：已确认 / 网络调研 / 用户（2026-11-05）

## UC-007：配置与处理预警

- 目标/价值：异常情况及时发现与处理（RA-001/RA-002）
- 参与者：农场管理员（配置）、种植员/养殖员（处理）
- 触发器：管理员配置阈值；系统产生预警

- 后置条件：预警可追溯、处理结果留痕
- 关联 FLOW/US/BR/AC：FLOW-001；US-003；BR-004；AC-003

## UC-008：政府监管端查看辖区汇总看板

- 目标/价值：监管部门对辖区农场实现网格化监督（数据汇总、预警、主体档案）（RA-001/Q-001 已决策）
- 参与者：政府监管人员
- 触发器：登录监管端
- 前置条件：监管人员账号已开通并被分配辖区（待确认：账号开通流程）
- 主成功场景：登录 → 选择辖区 → 查看农场/主体汇总数据（环境、预警、批次、溯源覆盖）→ 下钻查看单个农场详情

- 后置条件：监管查看行为留痕可审计

## UC-009：制定生产计划与维护农事模板

- 目标/价值：以计划驱动生产（品种、地块/塘口、茬口、目标产量），农事模板沉淀标准作业流程，支撑任务自动生成（RA-009/RA-010）
- 参与者：农场管理员
- 触发器：新茬口/新生产周期开始；或模板需修订
- 前置条件：地块与品种（含畜禽/水产品类）档案就绪
- 主成功场景：选择品种与地块/塘口 → 设定茬口/养殖周期与目标产量（Q-009 已决）→ 引用或编辑农事模板（各生长期标准作业与投入品清单；Q-011 已决：管理员维护，系统预置示例模板）→ 保存发布计划
- 扩展/异常：模板按区域/品种定制（行业做法，RA-010）；计划调整 → 未执行任务重新排期，已执行记录保留
- 远期扩展（RA-012）：模板升级为"区域+物种生命周期模型"（生老病死各阶段任务、每平方米/每头每只/每塘口物料定额），并按定额自动计算计划物料需求；一期只做模板，结构预留维度
- 后置条件：生产计划发布，可作为任务生成来源
- 关联 FLOW/US/BR/AC：FLOW-004；US-010；BR-008；AC-010
- 状态/来源/审批人：已确认 / 网络调研（RA-009/RA-010）/ 用户（2026-11-05）

## UC-010：农事任务派发与执行

- 目标/价值：任务到人、时限明确，执行结果回填，避免遗漏延误（RA-010 农事任务远程分配/审核/监督）
- 参与者：农场管理员（派发/审核）、种植员/养殖员（执行）
- 触发器：系统按计划/模板自动生成任务；或管理员手动创建/派发
- 前置条件：生产计划已发布（或临时任务来源已标注，BR-008）；作业人员已分配
- 主成功场景：任务生成（含责任人、时限、作业内容）→ 作业人员移动端接单执行 → 提交完成记录（进入 UC-003 作业留痕）→ 管理员审核，通过后任务闭环（Q-010 已决：需审核，可配置开关）
- 扩展/异常：任务逾期 → 系统提醒/升级；计划调整 → 未执行任务重新排期
- 后置条件：计划-任务-记录-批次全链路可追溯（BR-009）
- 关联 FLOW/US/BR/AC：FLOW-004（+FLOW-002 执行留痕）；US-011、US-012；BR-008、BR-009；AC-011、AC-012
- 状态/来源/审批人：待确认 / 网络调研（RA-010）/ PENDING
