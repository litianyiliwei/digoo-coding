## GIS 地图价值判断

| PAGE ID | 页面 | 价值判断 | 结论与理由 |
|---|---|---|---|
| PAGE-001 | 统一登录 | 无 | 不增加：登录不涉及空间信息 |
| PAGE-002 | 管理驾驶舱 | 高 | 已增加：一屏掌握地块分布、在产与预警落位 |
| PAGE-003 | 多地块环境监测 | 高 | 已增加：超阈值地块在地图上高亮，先看空间再看列表 |
| PAGE-004 | 设备远程控制 | 中低 | 不增加：设备卡片已标注所属地块，地图会挤压控制操作区 |
| PAGE-005 | 预警配置与处理 | 低 | 不增加：配置对象已有地块切换，地图信息增量有限 |
| PAGE-006 | 生产计划与农事模板 | 中低 | 不增加：页面重点是计划进度与模板，地块信息已在说明行 |
| PAGE-007 | 任务派发与审核 | 高 | 已增加：派发需判断任务落位与责任人覆盖 |
| PAGE-009 | 农资出入库管理 | 无 | 不增加：库存与地块关系弱 |
| PAGE-010 | 生产批次与溯源码 | 中 | 不增加：产地可视化由 PAGE-021 承担，管理端以状态与码为中心 |
| PAGE-012 | 政府监管汇总看板 | 高 | 已增加：网格化监管依赖辖区空间视图 |
| PAGE-013 | 系统管理 | 低 | 不增加：当前授权为列表；地图圈选授权列为后续候选 |
| PAGE-016 | 作业端工作台 | 高 | 已增加：作业人员需要知道"我的地块"位置与任务点 |
| PAGE-017 | 作业端我的任务 | 中 | 不增加：任务卡已带地块名，地图由 PAGE-016/018 覆盖 |
| PAGE-018 | 作业端任务详情与执行 | 高 | 已增加：到场作业需要目标地块位置与相邻地块参照 |
| PAGE-019 | 作业端环境监测 | 高 | 已增加：监测数据与地块空间对应，便于判断影响范围 |
| PAGE-020 | 作业端预警处理 | 高 | 已增加：预警按地块定位，便于现场处置 |
| PAGE-021 | 消费者扫码溯源页 | 中高 | 已增加：产地可视化提升可信度 |
| PAGE-022 | 管理中心 | 低 | 不增加：纯导航页，总览由驾驶舱地图承担 |

> 地图为示意层：地块以矩形/椭圆近似，未接入真实边界与坐标。PAGE-004、PAGE-013 的地图能力列为后续候选（设备分布图层、地图圈选授权）。
